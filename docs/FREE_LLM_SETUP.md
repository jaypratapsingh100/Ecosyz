# 🆓 Free LLM Setup for App Builder

## Quick Summary

Your App Builder now supports **multiple FREE LLM providers** so users can build frontend and backend applications **completely free**!

## 🎯 Best Options for Building Apps

### 1. **DeepSeek** (Recommended for Code) 💻
- ✅ **FREE** - No credit card needed
- ✅ **Best for code generation** - Specialized models
- ✅ **Two models:**
  - `deepseek-coder` - Optimized for code (Use this!)
  - `deepseek-chat` - General purpose

**Setup:**
1. Get API key: https://platform.deepseek.com/api_keys
2. In App Builder → Click ⚙️ → Select **DeepSeek**
3. Paste key → Select `deepseek-coder` → Save

**Perfect for:**
- Frontend apps (React, Next.js, Vue)
- Backend APIs (Node.js, Express)
- Full-stack applications
- Code debugging

### 2. **Groq** (Fastest) ⚡
- ✅ **FREE** - No credit card needed
- ✅ **Fastest responses**
- ✅ **High rate limits**

**Setup:**
1. Get API key: https://console.groq.com/keys
2. In App Builder → Click ⚙️ → Select **Groq**
3. Paste key → Select `llama-3.3-70b-versatile` → Save

**Perfect for:**
- Quick code generation
- Fast iterations
- High-volume usage

## 🚀 How Users Can Build Apps for Free

### Step 1: Get Free API Key

**DeepSeek (Recommended):**
```
1. Visit: https://platform.deepseek.com/
2. Sign up (free, no credit card)
3. Go to API Keys
4. Create new key
5. Copy key (starts with sk-)
```

**Groq (Alternative):**
```
1. Visit: https://console.groq.com/
2. Sign up (free, no credit card)
3. Go to API Keys
4. Create new key
5. Copy key (starts with gsk_)
```

### Step 2: Configure in App Builder

1. Open App Builder
2. Click ⚙️ icon in chat panel
3. Select provider (DeepSeek or Groq)
4. Paste API key
5. Select model:
   - DeepSeek: `deepseek-coder` (for code)
   - Groq: `llama-3.3-70b-versatile` (for speed)
6. Click **Save Settings**

### Step 3: Start Building!

**Frontend Example:**
```
User: "Create a React todo app with add, delete, and complete functionality"

AI generates:
- Complete React components
- Styling
- Working code
```

**Backend Example:**
```
User: "Create a Node.js API for user authentication"
AI generates:
- Express server setup
- Auth routes
- Middleware
- Complete backend code
```

**Full-Stack Example:**
```
User: "Build a blog app with React frontend and Node.js backend"
AI generates:
- Frontend components
- Backend API
- Database schema
- Complete application
```

## 💡 Tips for Best Results

1. **Use DeepSeek Coder for Code:**
   - Always select `deepseek-coder` model**
2. **Be Specific:** "Create a React component for user profile" vs "Make a component"
3. **Specify Framework:** "Create a Next.js API route" vs "Make an API"
4. **Request Complete Code:** "Create a complete Express server" vs "Show me code"

Users can also set API keys in `.env`:

```env

DEEPSEEK_API_KEY=sk-your-key-here

GROQ_API_KEY=gsk_your-key-here
```

The system automatically uses these if set.
