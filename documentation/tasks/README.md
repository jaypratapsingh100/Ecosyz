# App Studio Enhancement Tasks

Individual task files for spawning agents. **One task per chat/agent.**

## How to Use

1. Open a task file (e.g., `TASK-H1-over-fetch.md`)
2. Copy everything **below the `---` line**
3. Start a **new chat** and paste the content
4. The agent will complete the task independently
