## 🚀 Quick Start Guide

### **Step 1: Set Up Payment Gateway (Day 1)**
1. Create Razorpay account: https://razorpay.com
2. Get API keys (Key ID, Key Secret, Webhook Secret)
3. Add to `.env`:
   ```env
   RAZORPAY_KEY_ID=your_key_id
   RAZORPAY_KEY_SECRET=your_key_secret
   RAZORPAY_WEBHOOK_SECRET=your_webhook_secret
   NEXT_PUBLIC_RAZORPAY_KEY_ID=your_public_key_id
   ```

### **Step 2: Install Dependencies (Day 1)**
```bash
pnpm add razorpay
pnpm add @types/razorpay
pnpm add pdfkit  # For invoices
pnpm add recharts  # For analytics charts
```

### **Step 3: Create Payment Models (Day 2)**
1. Update `prisma/schema.prisma` with Payment model
2. Run migration: `npx prisma migrate dev --name add_payment_model`
3. Update User model relations

### **Step 4: Create Payment APIs (Day 3-4)**
1. Create `app/api/payments/checkout/route.ts`
2. Create `app/api/payments/webhook/route.ts`
3. Create `app/api/payments/subscription/route.ts`

### **Step 5: Create Checkout UI (Day 5)**
1. Create `app/components/billing/CheckoutButton.tsx`
2. Update `app/pricing/page.tsx` with checkout buttons
3. Test payment flow

### **Step 6: Enforce Usage Limits (Day 6-7)**
1. Create `app/lib/usage/limits.ts`
2. Create `app/lib/usage/check-limit.ts`
3. Add usage checks to APIs:
   - App Builder: `app/api/app-projects/route.ts`
   - AI Chat: `app/api/chat/route.ts`
   - Workspace: `app/api/workspaces/route.ts`

### **Step 7: Create Billing Dashboard (Day 8-9)**
1. Create `app/billing/page.tsx`
2. Create subscription management components
3. Create usage display components

### **Step 8: Test & Deploy (Day 10-14)**
1. Test payment flow end-to-end
2. Test usage limits
3. Test billing dashboard
4. Deploy to production
